Enhancement Layers — Two-Tier System

Universal Advanced Options + Widget-Specific Advanced Enhancements

Layer 1: Universal Advanced Options (ALL 86 widgets)

The 25 consistent props: background, border/shape, spacing/depth, entrance animation, hover effects. Every widget gets these.

Layer 2: Widget-Specific Advanced Enhancements

Beyond the universal set — intelligent, avant-garde controls unique to each widget's domain.

Typography Widgets

  • kineticText → character-level animation mode, split-by (char/word/line), wave amplitude
  • textScramble → charset customisation, decode trigger (hover/click/auto), scramble intensity
  • typewriterReveal → multi-text rotation, cursor style (blink/underscore/block), cursor colour
  • textMask → mask blend mode, mask scale, mask animation speed
  • morphingCounter → separator style, number format, easing curve
  • liquidText → wave type (sine/square/triangle), per-char randomisation, filter intensity
  • waveText → wave direction (up/down/left/right), phase offset, dual-colour wave
  • rotatingText3d → auto-rotate toggle, mouse-driven rotation, depth (Z-axis)
  • morphingText → morph direction, word count, highlight current word
  • kineticScramble → auto-scramble interval, reveal on scroll, cipher style

Cursor Widgets

  • particleTrail → particle SHAPE selector (circle/square/triangle/star/diamond/cross), trail fade mode, wind force
  • magneticCursor → element SHAPE (circle/square/dot/line), magnetic polarity toggle, repel mode
  • cursorRipple → ripple SHAPE (circle/diamond/star), multi-ripple toggle, ripple gradient
  • multiShapeTrail → shape morph speed, shape sequence order, per-shape colour mapping
  • cursorSpotlight → spotlight SHAPE (circle/ellipse/square/polygon), edge gradient, content reveal mode
  • magneticText → character attraction strength, elastic bounce, character SHAPE override
  • cursorDistortion → distortion type (lens/swirl/pinch/ripple), chromatic aberration toggle
  • colorSampler → swatch SHAPE, palette layout (horizontal/vertical/grid), copy-to-clipboard
  • gravityCursor → gravity well SHAPE, particle trail toggle, orbital mode

Physics Widgets

  • physicsSandbox → object SHAPE (circle/box/triangle), collision colour flash, gravity direction
  • imagePhysics → image SHAPE mask (circle/rounded/square), rotation on collision, bounce trail
  • bubblePop → bubble SHAPE, pop animation (shatter/fade/particle), pop sound toggle
  • gravityWells → well SHAPE visual, particle trail, well colour per strength
  • fluidSimulation → fluid colour mode (single/dual/rainbow), viscosity zones, turbulence
  • clothSimulation → cloth colour, tearable toggle, pin points, grid density
  • collisionChaos → spawn SHAPE, colour cycling, slow-mo toggle
  • blackHole → accretion disc SHAPE, event horizon size, particle trail glow

Scroll / Background / Effect Widgets

  • stickyScrollStack → card SHAPE, stack offset, card gradient, card hover lift
  • scrollVelocitySkew → skew direction, max skew, elastic snap-back
  • parallaxImageStack → layer SHAPE mask, parallax depth per layer, layer opacity curve
  • mosaicAssemble → cell SHAPE, assemble pattern (random/spiral/wave), cell border
  • scrollProgressRing → ring SHAPE (circle/square/hexagon), progress gradient, counter display
  • morphBlob → blob SHAPE presets, colour cycling, dual-blob mode
  • noiseGrain → noise type (grain/lines/dots), noise animation speed, colour overlay
  • gradientFlow → gradient SHAPE (linear/radial/conic), flow direction, colour stops (2-5)
  • glassmorphismStack → glass SHAPE, frosted amount, glass tint colour
  • tiltCard3d → card SHAPE, glare intensity, perspective depth, reverse tilt
  • glitchSection → glitch type (RGB split/slice/noise), glitch frequency, glitch colour A/B
  • audioVisualizer → bar SHAPE (rect/circle/triangle), visualizer mode (bars/wave/circle), colour gradient
  • holographicCard → hologram SHAPE, shimmer pattern, rainbow intensity
  • constellationLines → star SHAPE, connection style, pulse animation
Implementation Order

For each widget: (1) Add universal advanced props to defaultProps, (2) Enhance render with universal container + widget-specific features, (3) Build full editPanel with widget-specific controls + collapsible Advanced section. Present changes for approval before moving to next widget.

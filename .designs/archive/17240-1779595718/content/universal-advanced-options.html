Universal Advanced Options — For ALL 86 Widgets

Consistent advanced controls added to every widget's editPanel + render

Container Controls (all widgets)

Background

  • Background colour (picker)
  • Background type: solid / gradient
  • Gradient direction
  • Gradient colour 1 & 2
  • Background image URL
  • Background size/position

Border & Shape

  • Border radius (range: 0–50px)
  • Border width (range: 0–8px)
  • Border colour (picker)
  • Border style: solid / dashed / dotted
  • Shape preset: sharp / rounded / pill / circle

Spacing & Depth

  • Padding V / H (range)
  • Margin V / H (range)
  • Box shadow toggle
  • Shadow colour / blur / spread
  • Opacity (range: 0–100%)
Animation & Interaction (all widgets)

Entrance Animation

  • Animation type: none / fade / slide-up / slide-left / zoom / flip
  • Animation duration
  • Animation delay
  • Animation easing

Hover Effects

  • Hover effect: none / scale / lift / glow / rotate / shake
  • Hover scale amount
  • Hover transition speed
  • Hover shadow intensity
Implementation Strategy

Each widget gets these ~25 new advanced props added to its defaultProps, its render function wraps content in a configurable container, and its editPanel gets a collapsible "Advanced Options" section. The advanced options are CONSISTENT across all widgets — same prop names, same control types.

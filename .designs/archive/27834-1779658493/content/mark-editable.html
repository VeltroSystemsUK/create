🏷️ How to mark content as editable?

When building a page, how does the developer specify "this part can be edited by the client"?

A

Per-Prop Toggle in the Builder

When you select a block on the canvas, each prop in the right panel gets a small lock/toggle icon. Click to mark it as "client-editable." The Hero headline? Editable. The background color? Locked.

Headline 🔓 Editable ✓
Subtext 🔓 Editable ✓
Image URL 🔓 Editable ✓
Background Color 🔒 Locked
B

Editable Regions (Block-Level)

Instead of per-prop, mark entire blocks as "Content Block" vs "Design Block." A Hero block marked as "content" exposes all its text props as editable. A Footer block marked as "design" is locked entirely. Simpler but less granular.

📝 Hero — Content Block 🔧 Services — Design Block
Quick toggle per block in the left panel
C

Auto-Detect + Manual Override

By default, text and image props are editable; color, spacing, and layout props are locked. The developer can override per-prop. Smart defaults minimize setup — most blocks work out of the box.

✓ Headline → auto-editable (it's text)
✓ Image URL → auto-editable (it's media)
✗ Padding → auto-locked (it's layout)
✗ Accent Color → auto-locked (it's design)
Override any prop with one click

I recommend C (Auto-Detect + Override) — minimal setup, maximum control when needed. What do you think?

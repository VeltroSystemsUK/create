✅ Approach Summary — CMS for Framework Builder

Core Design

Content Scope All content except structural design — text, images, copy on every block
Editing Interface Both — inline editing on live site + admin dashboard
Editable Marking Auto-detect (text/image = editable, design = locked) + manual override per-prop
Backend Extend server.py with CMS API endpoints
Data Storage JSON files alongside the project (matches existing pattern)

How It Works End-to-End

1️⃣
Build Site
Developer builds site in Framework Builder. CMS auto-detects editable props.
2️⃣
Configure CMS
Override auto-detection if needed. Set client password. Export.
3️⃣
Client Edits
Client visits live site. Inline edit or /admin dashboard. Saves changes.
4️⃣
Live Updates
Content served via CMS API. Changes are immediate. Design stays intact.

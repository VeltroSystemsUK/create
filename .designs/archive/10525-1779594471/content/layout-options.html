C — Toolbar First

Prominent horizontal toolbar at top holds all drawing tools + context-sensitive properties inline (fill color, font, size). Slimmer side panels for elements and properties. Most canvas space, most Illustrator-like feel.

Click to select your preferred layout direction. All three will have proper element tiles, text presets, and a polished dark theme — the difference is where things live.

Interface Overview
Framework Builder is a visual page composer. You build pages by stacking and styling sections — no code required.
KEY AREAS
Top Bar
Device preview, undo/redo, save, load, import, export and settings live here.
Left Panel
Your section library, templates, layers and widgets. Click any section to add it.
Canvas
The live editing area. Click a block to select it, drag to reorder.
Right Panel
Appears when a block is selected. Edit content, style, typography, animations and more.
